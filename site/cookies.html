Cookies notice

We don't believe in tracking cookies. This page lists every cookie and every piece of local storage this site or the FormAlive extension creates — so you can audit it for yourself.

Effective: May 22, 2026 · Last updated: May 22, 2026

1. What's a cookie?

A cookie is a small text file a website asks your browser to store, usually for sign-in or tracking. Local storage is similar but only readable by the site that created it and never sent to a server automatically. FormAlive uses neither for tracking.

2. Cookies on this site

None. formalive.app sets zero cookies. We have no login, no shopping cart, no analytics, no ads.

3. Local storage on this site

Key Purpose Lifetime Type
formalive.cookie-consent Remembers that you dismissed the cookie banner so it doesn't keep appearing. Until you clear browser data Strictly necessary (first party)

That's the entire list. The value is accept:<timestamp> or decline:<timestamp> — no identifiers, no personal data. You can delete it any time from your browser's site-data settings.

4. Inside the FormAlive extension

The browser extension stores data inside the browser's extension storage (chrome.storage.local), not in cookies. Every field that contains personal information is encrypted with AES-256-GCM under a passphrase only you know. See the Privacy policy for the full breakdown.

5. Third-party requests this site makes

We don't embed analytics or ad scripts, but two helper resources load from public CDNs. They do not set tracking cookies on formalive.app:

Provider What it serves Why
Google Fonts (fonts.googleapis.com, fonts.gstatic.com) Inter & Plus Jakarta Sans Typography
Tailwind CSS CDN (cdn.tailwindcss.com) The Tailwind runtime Styling without a build step

Loading any resource from a third party involves standard request metadata (IP address, user agent). We don't pass them personal data and they don't write cookies to formalive.app.

6. How to clear or block

  • Clear our local storage: Browser settings → Privacy & security → Site data → search "formalive" → Remove.
  • Block all cookies for this site: Browser site settings → Cookies → Block.
  • Reset the cookie banner: Click "Decline" or "Got it" — both dismiss it. To see it again, clear the key listed above.

7. Changes

If we ever add a new cookie or storage key, we'll list it here before it ships, and we'll update the "Last updated" date. We won't quietly add tracking.
